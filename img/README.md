# תמונות

## 1. תמונות חופשיות — אוטומטי, בלי לעשות כלום

האפליקציה מושכת בעצמה תמונות אמיתיות מ־**ויקישיתוף** (Wikimedia Commons): מפות מחוזות,
בתי משפט, בתי כלא, אתרי הרצח, ערי הקורבנות וכלי הנשק. ויקישיתוף מכיל אך ורק מדיה חופשית,
והאפליקציה שולפת את שם היוצר ואת הרישיון מה־API ומציגה ייחוס אוטומטי מתחת לכל תמונה.

**מומלץ להוריד אותן לשרת שלנו** במקום להסתמך על ויקימדיה:

```bash
node tools/fetch-media.mjs
```

הסקריפט מוריד הכל ל־`img/commons/`, כותב `manifest.json` ו־`CREDITS.md`, והאפליקציה
תעדיף אוטומטית את הקבצים המקומיים. הריצו שוב אחרי כל הוספת תיק.

## 2. תמונות פרטיות — ידני

תמונות שאינן חופשיות (קלסתרונים, תצלומי מעצר, תמונות קורבנות, האיור של מרי קרסין)
אינן נמשכות אוטומטית. אם יש לכם זכות להשתמש בהן — שימו אותן כאן בשמות המדויקים הבאים.
קובץ קיים דורס את האיור; קובץ חסר פשוט לא מוצג, בלי שגיאה.

| שם הקובץ | מה זה |
|---|---|
| `logo.jpg` | לוגו הפודקאסט |
| `dillon-composite.jpg` | תומאס דילון — קלסתרון + תמונה מבית המשפט |
| `dillon-illustration.jpg` | האיור של מרי קרסין טיטו |
| `zelich-court.jpg` | סטיבן זליך בבית המשפט |
| `gamez-1.jpg` · `gamez-2.jpg` | ג'ני גיימז |
| `simonson-1.jpg` · `simonson-2.jpg` | לורה סימונסון |

סיומת אחרת (png / webp)? ערכו את אובייקט `IMG` בראש `assets/data.js`.

**המלצה:** רוחב עד 1200px, איכות ~80.
