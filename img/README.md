# תמונות

שים כאן קבצי תמונה בשמות המדויקים הבאים. כל קובץ שקיים מופיע אוטומטית באפליקציה;
כל קובץ שחסר מוחלף באיור SVG — בלי שגיאה ובלי ריבוע שבור.

| שם הקובץ | מה זה |
|---|---|
| `logo.jpg` | לוגו הפודקאסט |
| `dillon-composite.jpg` | תומאס דילון — הקלסתרון + התמונה מבית המשפט |
| `dillon-illustration.jpg` | האיור של מרי קרסין טיטו |
| `zelich-court.jpg` | סטיבן זליך בבית המשפט |
| `gamez-1.jpg` | ג'ני גיימז |
| `gamez-2.jpg` | ג'ני גיימז (2) |
| `simonson-1.jpg` | לורה סימונסון |
| `simonson-2.jpg` | לורה סימונסון (2) |

רוצה סיומת אחרת (png / webp)? ערוך את אובייקט `IMG` בראש `assets/data.js`.

**המלצה:** דחוס לרוחב 1200px לכל היותר, ואיכות ~80. התמונות נטענות ב-`loading="lazy"`.
