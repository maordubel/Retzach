# img/commons

תוכן התיקייה הזאת נוצר אוטומטית על ידי `node tools/fetch-media.mjs`.

- `manifest.json` — מיפוי מפתח → קובץ מקומי + יוצר + רישיון. כל עוד הוא `{}` האפליקציה
  מושכת את התמונות ישירות מוויקישיתוף בזמן ריצה.
- `CREDITS.md` — רשימת ייחוס מלאה, נוצרת יחד עם ההורדה.
- קבצי התמונות עצמם.

**אל תערכו קבצים כאן ידנית** — הריצו את הסקריפט מחדש.
